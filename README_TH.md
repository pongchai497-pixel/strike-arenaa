# Wasteland Co-op — 3D Survival

เกมต้นแบบ 3D ผ่านเว็บเบราว์เซอร์ มีห้องออนไลน์, ปุ่มควบคุมมือถือ, เก็บของ, คราฟต์, แผนที่เมืองร้าง/ฐานทัพ, ปืน 3 ชนิด และซอมบี้ที่ซิงก์ผ่านเซิร์ฟเวอร์

## สิ่งที่ต้องมี
- Node.js 18 หรือใหม่กว่า
- อินเทอร์เน็ตสำหรับโหลด Three.js จาก CDN
- ถ้าจะเล่นออนไลน์คนละเครื่อง ต้องนำโปรเจกต์นี้ไปโฮสต์บนเซิร์ฟเวอร์ที่เปิด WebSocket ได้

## เปิดทดสอบในเครื่อง
1. แตกไฟล์ ZIP
2. เปิด Terminal / Command Prompt ในโฟลเดอร์ `survival_online_game`
3. ติดตั้ง dependencies:
   ```bash
   npm install
   ```
4. เปิดเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
5. เปิด `http://localhost:8080` ใน Chrome / Edge

## เล่นกับเพื่อนในเครือข่าย Wi-Fi เดียวกัน
1. เปิดเซิร์ฟเวอร์บนคอมพิวเตอร์เครื่องหนึ่ง
2. หา IP ภายในเครือข่ายของเครื่องเซิร์ฟเวอร์ เช่น `192.168.1.20`
3. บนอุปกรณ์เพื่อน เปิด `http://192.168.1.20:8080`
4. คนแรกสร้างห้อง แล้วแชร์รหัสห้องให้เพื่อนใส่ช่องรหัสห้อง
5. อนุญาตพอร์ต 8080 ในไฟร์วอลล์หากระบบถาม

## เล่นออนไลน์ผ่านอินเทอร์เน็ต
ต้อง deploy โฟลเดอร์นี้ไปยังบริการโฮสต์ Node.js ที่รองรับ WebSocket เช่น VPS หรือ Node hosting:
1. อัปโหลดไฟล์โปรเจกต์ทั้งหมด (รวม `public/`)
2. รัน `npm install` และ `npm start` หรือใช้คำสั่ง Start ของแพลตฟอร์มเป็น `npm start`
3. เปิดพอร์ตที่แพลตฟอร์มกำหนดผ่าน environment variable `PORT`
4. เปิดเว็บ URL ที่ได้จากผู้ให้บริการ
5. หากเป็น HTTPS ให้กรอก URL WebSocket เป็น `wss://โดเมนของคุณ` ในช่องเซิร์ฟเวอร์เมื่อจำเป็น
6. แชร์ URL เว็บไซต์และรหัสห้องให้เพื่อน

> ยังไม่มีเซิร์ฟเวอร์ออนไลน์สาธารณะรวมมาให้ใน ZIP เพราะต้องมีบัญชีโฮสต์/โดเมนของเจ้าของเกม เกมจะออนไลน์ระหว่างอุปกรณ์ได้เมื่อเซิร์ฟเวอร์นี้กำลังทำงานและเข้าถึงได้จากอุปกรณ์อื่น

## ปุ่มควบคุม
### คอมพิวเตอร์
- `W A S D` เดิน
- คลิกเมาส์ค้างเพื่อยิงไปยังทิศที่เล็ง (ระบบต้นแบบ)
- `E` เก็บของใกล้ตัว
- `R` เติมกระสุน
- `1 / 2 / 3` เลือกไรเฟิล / ลูกซอง / ปืนกลมือ

### มือถือ
- ใช้ปุ่มทิศทางด้านซ้ายเพื่อเดิน
- แตะ/กดค้างปุ่มยิง
- `LOOT / E` เก็บของ
- `RELOAD` เติมกระสุน
- ใช้แผงสร้างอุปกรณ์ด้านขวาบน

## หมายเหตุของต้นแบบ
- เกมใช้ Three.js จาก CDN จึงต้องมีอินเทอร์เน็ตตอนเปิดเกม
- โหมดออนไลน์ใช้ Node.js + WebSocket (`ws`) และซิงก์ผู้เล่น ศัตรู ไอเทม ห้อง และของที่สร้าง
- ปัจจุบันเป็น prototype: ยังไม่มีบัญชีผู้ใช้/บันทึกถาวร, anti-cheat ขั้น production, ระบบฟื้นคืนชีพ, เสียง/แอนิเมชันเต็มรูปแบบ หรือการจัดการห้องแบบ production
- ปุ่มยิงบนเดสก์ท็อปเป็นระบบเล็งต้นแบบ; การเล็งเมาส์แบบเต็มหน้าจอและการปรับสมดุลปืนสามารถต่อยอดได้
